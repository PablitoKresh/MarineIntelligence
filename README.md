# ⚓ Marine Intelligence

Web temática inspirada en el universo de *One Piece*, planteada como el archivo de inteligencia de la Marina: los piratas más buscados, las categorías de Frutas del Diablo y las tripulaciones.

👉 **Demo:** [pablitokresh.github.io/MarineIntelligence](https://pablitokresh.github.io/MarineIntelligence/)

Proyecto de la asignatura *Tecnologías Avanzadas de Desarrollo* (Universidad Pablo de Olavide).

---

## ✨ Qué incluye

- **Los más buscados:** carrusel interactivo con efecto *coverflow* (Swiper.js) con los carteles de recompensa.
- **Frutas del Diablo:** secciones por categoría.
- **Tripulaciones:** información organizada en un acordeón de Bootstrap.
- **Diseño responsive**, adaptado a móvil, tablet y escritorio.

## 🛠️ Tecnologías

- HTML5 y CSS3
- JavaScript
- Bootstrap 5.3
- Swiper.js 11

Sin dependencias que instalar: las librerías se cargan por CDN.

## 🚀 Verlo en local

```bash
git clone https://github.com/PablitoKresh/MarineIntelligence.git
cd MarineIntelligence
```

Abre `index.html` en el navegador.

## 📁 Estructura

```
index.html      página principal
css/style.css   estilos propios
js/main.js      configuración del carrusel
img/            carteles, frutas y logo
```
